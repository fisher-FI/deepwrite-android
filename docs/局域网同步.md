# 局域网同步：手机直连电脑

目标：**电脑当网盘，手机在同一局域网内直连电脑**，两端都能读写同一批作品。
电脑可用网线、手机可用 WiFi，只要连同一台路由器且没有客户端隔离即可；不依赖坚果云或 ngrok。

## 架构

```
 手机 (DeepWrite Android)                电脑
 ┌────────────────────┐          ┌──────────────────────────────┐
 │ 双端同步            │  http    │ dav-server.mjs :8765          │
 │ endpoint=192.168.0.59│ ───────► │   └─ sync-root/              │
 │                    │  同一局域网 │                              │
 └────────────────────┘          │ DeepWrite 桌面端              │
                                  │ endpoint=127.0.0.1:8765      │
                                  └──────────────────────────────┘
```

两端都是**客户端**，连同一个 WebDAV 服务、同一个「同步空间」。
电脑端负责把作品传上去，手机端拉下来（也可以反向）。

## 前置条件

1. 手机和电脑在**同一个局域网/同一台路由器**（例如电脑网线连接、手机连该路由器 WiFi；访客 WiFi 或 AP 客户端隔离可能阻断互访）。
2. 电脑装了 Node（`node -v` 能跑）。
3. 手机装的是**本 fork 构建的 APK**（`DeepWrite-Android-1.5.19-lan.apk`）——
   原版 APK 既连不上（缺 `net.request`），也不接受 http 地址。

## 第一步：电脑上启动同步服务

```bash
cd E:\projects\deepwrite-sync
start-sync.cmd
```

或手动：

```bash
node dav-server.mjs --root ./sync-root --host 0.0.0.0 --port 8765 \
                    --user deepwrite --pass deepwrite
```

看到 `WebDAV 就绪 http://0.0.0.0:8765/` 就成了。**保持这个窗口开着。**

先自检一下（另开一个窗口）：

```bash
node test-client.mjs http://127.0.0.1:8765 DeepWriteSync deepwrite deepwrite
```

## 第二步：放行防火墙

Windows 默认会拦掉外部对本机端口的访问。以**管理员**身份运行：

```powershell
New-NetFirewallRule -DisplayName "DeepWrite LAN Sync" -Direction Inbound `
  -Protocol TCP -LocalPort 8765 -Action Allow -Profile Private
```

> `-Profile Private` 表示只对「专用网络」放行。若你的 WiFi 被识别成「公用网络」，
> 改成 `-Profile Any`，或把该网络设为专用。
>
> 临时验证：先在手机上用浏览器打开 `http://192.168.0.59:8765/`，
> 能弹账号密码框（或返回 401/404）就说明通了。

## 第三步：电脑端（DeepWrite 桌面端）

桌面端跑的是 `E:\deepwrite` 的源码，需要**先放开 http**（已改好）：

```
E:\deepwrite\packages\contracts\src\device-sync\connection-schemas.ts
```

改动就一处（上游只允许 https）：

```diff
- url.protocol === "https:" &&
+ (url.protocol === "https:" || url.protocol === "http:") &&
```

然后正常启动桌面端（`pnpm dev` 或你平时的方式），进「双端同步」：

| 字段 | 填 |
| --- | --- |
| 服务商 | **通用 WebDAV**（不要选坚果云） |
| 地址 | `http://127.0.0.1:8765` |
| 账号 | `deepwrite` |
| 应用密码 | `deepwrite` |
| 同步目录 | `DeepWriteSync` |

点「连接网盘」→ 应当列出同步空间 → **建立**一个新空间（例如叫 `lan`）。
连接成功后，选要同步的作品，**上传**到空间。

> 界面文案可能随版本略有差异；核心就是「通用 WebDAV + 上面那组地址账号」。
> 电脑端用 `127.0.0.1` 就行（它和服务在同一台机器上，不必绕局域网）。

## 第四步：手机端

1. 装 `DeepWrite-Android-1.5.19-lan.apk`。
   - ⚠️ 签名与原版不同，**要先卸载原版**（`/data/data` 的配置和 API key 会丢；
     作品在 `/sdcard/Download/DeepWrite`，不受影响）。
   - 装完记得授予**「所有文件访问」**。
2. 进「双端同步」，在手机上**手动连接**电脑的 WebDAV 服务。不要依赖桌面端显示的接入二维码：它会把桌面端保存的 endpoint（这里是 `127.0.0.1`）原样编码，手机上的 `127.0.0.1` 指向手机自身；而当前 Android 移植版也没有扫码/导入接入码的入口。
3. 用和电脑端相同的账号、密码、同步目录连接后，在空间列表里**选择电脑端刚建立的同一个空间**：

| 字段 | 填 |
| --- | --- |
| 服务商 | 通用 WebDAV |
| 地址 | `http://192.168.0.59:8765` |
| 账号 / 应用密码 | `deepwrite` / `deepwrite`（**示例弱口令，先换成强口令**） |
| 同步目录 | `DeepWriteSync`（要和电脑端一致） |

4. 连上后选空间，**下载**作品。

## 数据在哪

| 位置 | 内容 |
| --- | --- |
| `E:\projects\deepwrite-sync\sync-root\DeepWriteSync\` | 同步空间的实体（电脑上的落盘） |
| 手机 `/sdcard/Download/DeepWrite` | 手机端作品（文件管理器可见） |
| 手机应用私有目录 | 配置 / 模型 key（卸载即清） |

## 常见问题

| 现象 | 原因 / 处置 |
| --- | --- |
| 手机报「无法连接网盘」 | 手机和电脑不在同一局域网 / 访客 WiFi 或 AP 隔离 / 防火墙没放行 / 服务没起。先用手机浏览器开 `http://192.168.0.59:8765/` 验证 |
| 手机报「请填写有效的 HTTPS 地址」 | 装成了原版 APK，不是本 fork 的 `-lan` 包 |
| 电脑端报同样的 https 错 | 桌面端源码没改，或改了没重启 |
| 电脑 IP 变了 | DHCP 重新分配了。建议在路由器给电脑做**静态绑定**（MAC 保留） |
| 连接成功但列表为空 | 空间还没建立，或两端「同步目录」填得不一样 |
| 提示「作品正在生成或保存」 | 电脑端有生成任务在跑，等它结束再同步 |

## 局限（明确一下）

- **只能同局域网**。出门、换网就连不上（要外网就得走 ngrok / cloudflared 隧道）。
- 服务是**明文 http + Basic 认证**，口令在网线上是明文的。**只在可信局域网用**，
  别把 8765 暴露到公网。
- 服务进程要一直开着；关掉窗口 = 同步不可用。
- 尚未在真机上跑通完整同步（本套是静态修复 + 本地自检），第一次用请留意日志。

## 回滚

桌面端源码改动是一行，还原：

```diff
- (url.protocol === "https:" || url.protocol === "http:") &&
+ url.protocol === "https:" &&
```

手机端换回原版 APK 即可（或装回 `DeepWrite-Android-1.5.19-patched.apk`）。
